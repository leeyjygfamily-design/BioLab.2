# BioLab Analyzer
생명공학 데이터 분석 및 AI 기반 학습 지원 웹사이트

[웹사이트 접속](https://biolab2.streamlit.app/)

## 처음 사용하는 경우
홈 · 사용 가이드에서 원하는 메뉴를 선택한다. 표는 좌우 스크롤이 가능하다. 분석 결과는 교육용이며 실험적 검증을 대체하지 않는다.

## DNA 분석
기준 서열 설정 → 기본 분석 → ORF 및 변이 분석 결과 확인. NCBI 검색은 등록번호와 유전자명 검색을 지원한다. ORF는 번역 후보 구간이며 실제 CDS와 동일하지 않다. GC 함량은 G와 C의 비율이다. 정렬은 Biopython의 국소 정렬을 사용하며 미정렬 구간은 해석에 제한이 있다.

## BCA 단백질 정량
1. 초기 가상 표준용액 및 미지 시료 데이터를 확인한다.
2. 입력값 저장 및 BCA 분석 버튼을 누른다.
3. 표준곡선, R², 잔차, 농도 결과를 확인한다.

예시 표준 농도(mg/mL): 0, 0.25, 0.5, 1, 1.5, 2. 대응 흡광도: 0, 0.10, 0.21, 0.41, 0.62, 0.82. 미지 시료 흡광도 0.30, 희석배수 1. 실제 실험값이 아닌 가상 데이터이다. R²는 직선 적합도, CV는 평균에 대한 표준편차 비율이다. 외삽 및 추출 손실에 주의한다. 입력표 ZIP 백업 및 복원을 지원한다.

## PCR 프라이머 분석
페이지에 제공된 교육용 예시와 분석 결과의 의미 및 한계를 확인한다. 완전 일치 기반의 예측이며 실제 실험 성공을 보장하지 않는다.

<!-- assets/pcr.png -->

## AI 생명공학교사
필요한 분석 데이터만 선택하고 질문한다. 일반 질문은 데이터 선택 없이 가능하다. 질문 예시: ‘R²가 높아도 정량 정확성이 보장되지 않는 이유는?’ 답변은 별도로 검증한다. 선택 데이터와 질문은 Gemini API에 전송되므로 개인정보를 입력하지 않는다. 대화 기록은 TXT로 다운로드할 수 있다.

<!-- assets/ai.png -->

## 데이터 유지 및 복원
같은 세션에서 제출한 결과가 유지될 수 있으나 새로고침 시 초기화될 수 있다. BCA 입력표 ZIP 복원, AI 대화 TXT 열람, 홈의 설명 수준 설정 JSON 복원을 지원한다. 전체 분석 세션 복원은 지원하지 않는다.

## 기술 및 출처
Python, Streamlit, Pandas, NumPy, Plotly, Biopython, NCBI E-utilities, Google Gemini API. API 키는 Streamlit Secrets에서 관리하며 저장소에 올리지 않는다.

## 한계
교육용 분석 도구이며 실제 실험 또는 의료적 판단을 대체하지 않는다. 모바일 레이아웃과 API 동작은 배포 환경에서 검증해야 한다.
